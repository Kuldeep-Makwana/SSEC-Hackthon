# 🎓 College Website — Hackathon Project

A complete and responsive **College Website** built during a hackathon.
The site provides information about all departments, college events, gallery, videos, contact details, and more.
Made using **HTML, CSS, and JavaScript** with a neat folder structure and easy navigation.

## 🌟 Features

✔️ **Homepage** with quick navigation
✔️ **Department-wise detailed pages:**

* 🧑‍🏫 General
* 🛠️ Mechanical Engineering
* 🧱 Civil Engineering
* ⚡ Electrical Engineering
* 📡 Electronics & Communication (EC)
* 💻 IT Engineering
* 📚 Other departments

✔️ **About the College**
✔️ **Photo Gallery** with campus images
✔️ **Video Section** showing events & campus life
✔️ **College Events Page**
✔️ **Contact Page** with form & details
✔️ Responsive & clean UI
✔️ Fully static and fast — no backend required

## 🚀 Getting Started

### 🔹 Clone the Repository

```bash
git clone https://github.com/Kuldeep-Makwana/college-website-hackathon.git
```

### 🔹 Open the Project

1. Go to the project folder
2. Open **html/index.html** in any browser
3. Explore the website 🎉
